---
title: "What is Hermes Agent"
description: "An open-source, self-improving personal AI assistant that runs on your own infrastructure"
---

Hermes Agent is an open-source AI agent from **Noose Research**. It's MIT licensed and one of
the fastest-growing open-source projects on GitHub. Unlike a hosted assistant, Hermes runs on
**your own infrastructure** and grows with you over time through a self-improving loop built on
[skills](/hermes/concepts#pillar-2-skills) and [memory](/hermes/concepts#pillar-1-memory).

<Note>
  This guide summarizes the key concepts, models, and steps for going from zero to your own
  personal AI assistant. Credit to **Nate Herk** for the original walkthrough.
</Note>

## Where it runs

Hermes is lightweight enough to run almost anywhere.

## The mindset shift

<Warning>
  If you're confused about anything Hermes-related, **ask Hermes**.
</Warning>

Hermes can read its own documentation and figure out how to install or use new things. Drop in
an X post link or a documentation URL and tell it to implement what you want — it will do the
research and wire it up for you.
