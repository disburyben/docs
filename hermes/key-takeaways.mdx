<Steps>
  <Step title="Use the right tool for the job">
    Hermes is best for **on-the-go automation through Telegram**. Claude Code stays the daily
    driver for desk-bound knowledge work.
  </Step>
  <Step title="Learn the five pillars">
    [Memory, Skills, Soul, Crons, and the Self-Improving Loop](/hermes/concepts) are the mental
    model for everything Hermes does.
  </Step>
  <Step title="Deploy the easy way">
    Use the Hostinger **one-click Docker install** on Ubuntu 24.04 LTS. Code **`NATEHURK`** gets
    10% off annual plans.
  </Step>
  <Step title="Track your agents">
    Always set up a [Claude Code project](/hermes/managing-agents) to track your VPS agents
    (passwords, IPs, configs). It pays off the first time something breaks.
  </Step>
  <Step title="Back up to GitHub first">
    The first thing after onboarding: [connect Hermes to a private GitHub repo](/hermes/github-backup)
    and set a daily backup cron.
  </Step>
  <Step title="Protect your keys">
    Never paste API keys into chat. Use `hermes config set KEY_NAME <value>` from inside the
    Docker container.
  </Step>
  <Step title="Treat each agent like a new hire">
    [Principle of least privilege](/hermes/security), named API keys per agent, and separate
    accounts where possible.
  </Step>
  <Step title="Check memory first when things break">
    Stale `memory.md` is the **number one cause** of weird agent behavior.
  </Step>
</Steps>
